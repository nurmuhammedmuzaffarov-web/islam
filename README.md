# Islam

Мобильное приложение для мусульман (iOS и Android, Expo / React Native).
Интерфейс на кыргызском, русском и английском языках.

## Что есть в v0.1

- **Намаз.** Время пяти намазов и восхода по GPS или по выбранному городу Кыргызстана. Крупно показан следующий намаз с обратным отсчётом.
- **Азан.** Локальные уведомления на 12 дней вперёд. Расписание пересоздаётся при каждом открытии приложения.
- **Кибла.** Компас с направлением на Каабу и вибрацией, когда телефон повёрнут правильно.
- **Коран.** Аль-Фатиха, аль-Кахф, Йа Син, аль-Мульк, 30-й джуз (суры 78–114) и аят аль-Курси. Арабский текст и перевод смыслов на языке интерфейса, сноски переводчика.
- **Зикр и дуа.** Истигфары, зикры и дуа. Сверху арабский текст, под ним транскрипция кириллицей и смысл на языке интерфейса, внизу ссылка на хадис. Есть счётчик-тасбих, тасбих после намаза идёт по шагам: 33 + 33 + 33 + 1.
- **Настройки.** Язык, город, метод расчёта, мазхаб для асра, поправки в минутах для каждого намаза.

## Запуск

```bash
npm install
npx expo start
```

Откройте QR-код в приложении Expo Go или запустите эмулятор.

```bash
npm test          # тесты расчёта времени намаза и киблы
npm run typecheck
```

## Источники текстов

Все религиозные тексты скачиваются скриптами из официальных источников, а не набираются вручную.

| Что | Источник | Скрипт |
|---|---|---|
| Арабский текст Корана | [QuranEnc](https://quranenc.com) (текст Мединского мусхафа) | `npm run fetch:quran` |
| Перевод смыслов на кыргызский | QuranEnc, Шамсуддин Хакимов (`kyrgyz_hakimov`) | 〃 |
| Перевод смыслов на английский | QuranEnc, Saheeh International / Noor International Center (`english_saheeh`) | 〃 |
| Перевод смыслов на русский | [Quran.com](https://quran.com), Эльмир Кулиев (на QuranEnc русского перевода нет) | 〃 |
| Зикры и дуа: арабский текст, переводы, кыргызская транскрипция, степень достоверности | [HadeethEnc](https://hadeethenc.com) | `npm run build:dhikr` |
| Шрифт для текста Корана | KFGQPC HAFS Uthmanic Script, Комплекс короля Фахда (тот же файл, которым пользуется QuranEnc) | `scripts/fetch-quran-font.sh` |

`build:dhikr` берёт каждую строку из официального текста хадиса и падает, если хоть одна строка в источнике не найдена.

Где официального текста нет, приложение говорит об этом прямо:
- у четырёх хадисов нет перевода на кыргызский на HadeethEnc, поэтому показывается русский перевод с пометкой;
- транскрипция четырёх зикров составлена вручную, у них стоит пометка «Транскрипция расмий булактан эмес».

Лицензия шрифта — `assets/fonts/KFGQPC-LICENSE.txt`: использовать и распространять бесплатно можно, продавать и изменять нельзя.

## Требует проверки до выпуска

1. **Метод «Кыргызстан» — предварительный.** Сейчас это углы MWL (фаджр 18°, иша 17°) и ханафитский аср. Официальные параметры ДУМК найти не удалось. Нужно сверить с расписанием муфтията и подогнать углы или поправки (`src/lib/prayer.ts`).
2. **Транскрипция, составленная вручную** (4 зикра с пометкой в `src/data/dhikr.json`, `translitOfficial: false`) — нужна проверка знающим человеком.
3. **Звук азана.** Пока играет стандартный звук уведомления. Свой азан нужно добавить отдельным аудиофайлом.

src/components/   UI-компоненты и иконки

src/i18n/         строки интерфейса ky / ru / en
src/lib/          расчёт намаза, геолокация, уведомления, настройки
